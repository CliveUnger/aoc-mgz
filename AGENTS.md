# aoc-mgz

This project is a fork of the original aoc-mgz which parses AOE2 replay files for further analysis.

- Do not open PRs to the original project unless specifically asked.
- Use conventional commits with simple and high level messages, for example:
  - feat: allow provided config object to extend other configs
  - docs: correct spelling of CHANGELOG
  - fix: prevent racing of requests
- Add python >=3.12 style typing to function signatures incrementally while updating code.
